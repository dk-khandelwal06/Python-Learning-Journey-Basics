## 📖 About This Repository

This repository is a personal archive of my Python learning journey. It contains the code, exercises, and mini-projects I worked through while learning Python, organized chapter by chapter.

It includes:

- Chapter-wise Python programs
- Practice sets for each chapter
- Additional practice questions
- Standalone projects
- Larger "mega projects" that combine multiple concepts

I created this repository to preserve my learning work online, track my progress over time, and keep my local machine organized without losing any of the code I've written along the way.

This is **not a tutorial repository** — it's a personal record of hands-on practice, mistakes, and improvements made while learning.

## 💻 How to Use This Repository

Clone the repository to explore the code locally:

```bash
git clone <repository-url>
cd Python-Learning-Journey
```

From there:

1. Navigate into any chapter, practice set, or project folder
2. Open the relevant `.py` file(s)
3. Run them using:

```bash
python filename.py
```

Each folder is self-contained and can be explored independently.
